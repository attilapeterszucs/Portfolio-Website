# Portfolio Website

I built this website as my personal portfolio to showcase my work experience, projects, and education in cyber security and industrial automation. It also has a blog where I post about hackathons, cyber security events, and conferences I attend.

## How This Site Was Built

| | |
|---|---|
| **Type** | Custom SPA (No CMS) |
| **Framework** | React 19 + TypeScript + Vite |
| **UI Components** | Shadcn/UI + Tailwind CSS v4 |
| **Hosting** | Vercel |
| **Domain** | Registered at Name.com via GitHub Education |
